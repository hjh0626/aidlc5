# Requirements Document

## Intent Analysis

데일리샷과 유사한 주류 예약 O2O 플랫폼의 POC 개발. [upstream:intent-statement]
가맹 리쿼샵과 제휴하여 소비자가 프리미엄 주류를 앱에서 예약하고 매장에서 픽업하는 서비스. [upstream:intent-statement]

**목표:**
- 주류 검색 → 예약 → 결제 → 픽업의 핵심 플로우 기술적 검증 [Q1]
- 가맹점 관리 및 품질 통제 메커니즘 구현 [Q4]
- 모바일 앱 기반 사용자 경험 검증 [Q5]

## Functional Requirements

### FR1. 사용자 인증 [Q2]

#### FR1.1 회원가입/로그인
- 이메일 또는 소셜 계정으로 회원가입 지원
- 로그인/로그아웃 기능 제공

#### FR1.2 성인 인증
- 주류 구매 전 성인 인증 필수 (만 19세 이상)
- 본인 인증 서비스 연동 (PASS, 카카오 인증 등)
- 인증 완료 상태 저장 및 확인

### FR2. 주류 카탈로그 [Q1, Q3]

#### FR2.1 주류 검색
- 키워드 검색 (주류명, 브랜드, 종류)
- 카테고리별 필터링 (위스키, 와인, 맥주, 소주 등)
- 가격대별 필터링

#### FR2.2 주류 상세 정보
- 주류 기본 정보 (이름, 브랜드, 종류, 도수, 용량)
- 가격 정보 (매장별 상이 가능)
- 상품 이미지
- 평점 및 리뷰 표시 [Q1]

#### FR2.3 주류 평점/리뷰 [Q1]
- 구매 완료 사용자의 평점 등록 (1-5점)
- 텍스트 리뷰 작성
- 리뷰 목록 조회

### FR3. 가맹점 관리 [Q4]

#### FR3.1 가맹점 조회
- 가맹점 목록 조회
- 위치 기반 가까운 매장 검색
- 가맹점 상세 정보 (주소, 연락처, 영업시간)

#### FR3.2 가맹점 재고 확인
- 매장별 주류 재고 현황 조회
- 재고 부족/품절 표시

#### FR3.3 가맹점 평가/신고 [Q4]
- 가맹점 평점 등록
- 문제 신고 기능:
  - 가격 부풀리기 (앱 가격과 실제 가격 불일치)
  - 불친절한 서비스
  - 잘못된 재고 정보 (품절인데 판매중 표시 등)
- 신고 내역 관리자 확인

### FR4. 예약 기능 [Q1]

#### FR4.1 예약 생성
- 주류 선택 및 수량 지정
- 픽업 매장 선택
- 픽업 희망 일시 선택
- 예약 확인 및 생성

#### FR4.2 예약 관리
- 내 예약 목록 조회
- 예약 상세 정보 확인
- 예약 취소 기능

#### FR4.3 예약 상태 관리
- 예약 상태: 대기중 → 확정 → 픽업완료/취소
- 상태 변경 시 사용자 확인 가능

### FR5. 결제 기능 [Q1]

#### FR5.1 결제 처리
- PG사 연동 (토스페이먼츠, 아임포트 등)
- 신용카드/체크카드 결제
- 간편결제 (카카오페이, 네이버페이 등)

#### FR5.2 결제 내역
- 결제 완료 확인
- 결제 내역 조회
- 환불 요청 (예약 취소 시)

## Non-Functional Requirements

### NFR1. 성능
- 앱 초기 로딩: 3초 이내
- 검색 결과 응답: 2초 이내
- 동시 접속자 100명 지원 (POC 기준)

### NFR2. 보안 [Q2]
- HTTPS 통신 필수
- 사용자 비밀번호 암호화 저장
- 성인 인증 정보 안전한 관리
- 결제 정보 PCI-DSS 준수 (PG사 위임)

### NFR3. 사용성
- 모바일 최적화 UI/UX [Q5]
- 직관적인 예약 플로우 (3단계 이내)
- 한국어 지원

### NFR4. 데이터
- 자체 데이터베이스 구축 [Q3]
- 데이터 백업 일 1회
- 주류 정보 CRUD 관리

## Constraints

### 기술 제약
- 모바일 앱 전용 (웹 버전 제외) [Q5]
- React Native 또는 Flutter 사용 [Q5]
- 푸시 알림 미포함 (POC 범위 외) [Q6]

### 비즈니스 제약
- 주류 판매는 성인에게만 허용 (주세법 준수)
- 온라인 주류 판매는 예약/픽업 형태로만 가능 (배달 불가)
- 가맹점 제휴 계약 필요 (POC에서는 테스트 데이터 사용)

### 법적 제약
- 청소년 보호법 준수 (성인 인증 필수)
- 개인정보보호법 준수
- 전자상거래법 준수

---

## Assumptions

1. POC 단계에서는 실제 가맹점 없이 테스트 데이터로 진행 [assumption]
2. 결제 연동은 테스트 모드로 구현 [assumption]
3. 성인 인증은 외부 서비스 연동 가능 [assumption]
4. 모바일 앱은 iOS/Android 모두 지원 예정 (크로스 플랫폼) [Q5]
